# notes

Short notes for people and agents, served as MCP tools (`notes mcp`) and CLI commands (`notes add-note`, `notes list-notes`, `notes delete-note`).

It is Rumblestrip's sandbox: an app made from [Rumblestrip's template](https://github.com/McReaper/rumblestrip-go/tree/main/template), where each Rumblestrip release is tried on real changes.

You read `features/`, the spec. The agent reads `AGENTS.md`.
